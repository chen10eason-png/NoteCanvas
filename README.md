# NoteCanvas V5.21.0 — 第六階段：錄音筆記

新增 iPad Safari 可用的瀏覽器麥克風錄音、每本筆記的錄音清單、回放、重新命名、下載、刪除，以及跳轉錄音開始時的頁面。錄音存於獨立 IndexedDB audio store，避免增加原有筆記 JSON 大小。

**注意**：必須在 HTTPS / localhost 使用並允許麥克風。錄音在停止後才儲存；關閉頁面前請停止錄音。錄音不包含在原有 JSON 備份中，也不提供筆跡同步重播或雲端同步。建議重要錄音另行下載備份。

首頁、程式、Service Worker 快取、檔名同步為 V5.21。保留原有資料與書寫功能。
