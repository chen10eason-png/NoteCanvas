# NoteCanvas V3
iPad-first handwriting notes PWA.

Key features:
- Apple Pencil Only is ON by default: touch is reserved for scrolling/panning/zooming.
- IndexedDB notebook storage.
- PDF import and annotation (PDF.js CDN).
- Vector handwriting/highlighter/eraser.
- Lasso selection foundation, movable objects.
- Image insertion, text boxes, shapes, tape, reusable element sample.
- Page add/duplicate/delete/reorder.
- Grid/lined/dotted/blank paper.
- Read mode, zoom, undo/redo, PNG export.
- Responsive iPad/mobile/desktop UI.

For PDF import, internet access is needed the first time PDF.js loads from CDN.
