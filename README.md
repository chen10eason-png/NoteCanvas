# NoteCanvas V5.22.1 — 書寫流暢度專項

本版從 V5.21 升級：共用書寫/匯出筆跡繪製器、二次曲線平滑、壓力感應筆觸、收集 coalesced Pointer Events、單點落筆可見、螢光筆緩衝畫布重用、書寫工具列加大觸控目標。保留 Pencil Only、手指連續捲動與雙指縮放。

注意：尚未在實際 iPad / Apple Pencil 上量測延遲或測試全部機型。匯入舊筆記仍相容；更新前建議匯出 JSON 備份。
